01. Introduction

E0 Equation Language is a declarative constraint language and interactive browser playground for solving systems of arithmetic, logical, and bitwise equations. Instead of writing step-by-step instructions to compute an answer, you state the mathematical conditions that the unknown variables must satisfy, and the solver searches for valid values automatically.

Every variable in E0 is modeled as a fixed-width binary number with an explicit bit-width configured via the size directive. Under the hood, the engine combines interval arithmetic (narrowing down the possible numeric bounds of each expression) with backtracking search over individual bits and boolean decisions. Everything runs locally inside your browser in a background Web Worker with zero server setup.

Enter an equation in the editor, for example x + x = 4, then press the "Solve" button. You must specify the number of bits allocated for each number, e.g., for an 8-bit number: size 8 0.

For calculations involving fractions, specify both the number of fractional and integer bits:

x + x = 7

size 5 1

If you encounter the error message "Invalid number", try to increase the number of bits: 

x + x = 1024

size 11 0

Adding a '+' to 'size' ensures that all calculated values will be non-negative: 

size + 8 0

Design Notes & Limitations

Educational Purpose & Solver Performance

This solver is based on interval arithmetic combined with a simple backtracking search for boolean variables. It is generally slow and performs even worse with modular arithmetic and bitwise operations. This project was created exclusively for educational purposes.

Declarative Constraints & External Code Generation

E0 has no standard loops (like for or while) or classic imperative branching. Instead of step-by-step instructions, you describe the problem using declarative equations and constraints.

A template-style preprocessor is planned for upcoming releases. However, even after templating is added, it is still better to generate E0 code using your favorite programming language.
